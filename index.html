Dive Logs

Downloads every dive header and profile using read-only commands. The first download takes about 1–2 minutes; afterwards only new profiles are read. The logbook is saved in this browser, so you can view and export it later without connecting.

Dive

 

Dives (tap a dive to see its profile)

This firmware stores profiles in a 256-sector ring but reads them back without wrapping, so the newest dives are only partly (or not) readable, and the oldest profiles were overwritten. Dives without a profile are still exported with date, duration, max depth and temperature.
